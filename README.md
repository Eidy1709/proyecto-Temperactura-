# Proyecto Temperatura

El programa recibe las temperatuas de una semana (lunes a domingo)

Calcula y muestra las temperatuas mínima y máxima de la semana

Calcula y muestra el promedio de temperatura de la semana

Muestra las temperaturas mayores que el promedio de la semana

Si una temperatura es mayor que 40 grados, muestra una alerta

Si una temperatura es menor que 0 grados, muestra una alerta

## Ejecución del programa

Para ejecutar el programa se debe utilizar el intérprete de python con el módulo main.py

```
$ python3 main.py
```
